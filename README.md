## 🏢 SaaS / Commercial Platforms

The AI coding assistant market has consolidated around a $200/month “power user” ceiling, with Windsurf Max, Cursor Ultra, and Claude Code Max all competing at the same price point. GitHub Copilot transitioned to usage-based billing on June 1, 2026, with plans including AI Credits aligned 1:1 with subscription prices . Windsurf, now owned by Cognition AI, abandoned the credit system in March 2026 in favor of daily/weekly quotas that refresh automatically . Cursor introduced a new India-specific plan (Cursor Start) at ₹649/month to capture price-sensitive developers in the region .

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[OpenHands](https://github.com/All-Hands-AI/OpenHands)** [![Stars](https://img.shields.io/github/stars/All-Hands-AI/OpenHands?style=social&color=white)](https://github.com/All-Hands-AI/OpenHands/stargazers)  
  **Open-source platform for software development agents**, MIT licensed. ~40k+ stars. Agents that can modify code, run commands, browse the web, and call APIs. The most popular open-source autonomous coding agent framework. 🖐️

- **[Cline (formerly Claude Dev)](https://github.com/cline/cline)** [![Stars](https://img.shields.io/github/stars/cline/cline?style=social&color=white)](https://github.com/cline/cline/stargazers)  
  **Autonomous coding agent for VS Code**, Apache-2.0 licensed. ~30k+ stars. Can create/edit files, run terminal commands, and use the browser. Supports OpenRouter, Anthropic, OpenAI, Google Gemini, AWS Bedrock, and local models via Ollama. 📎

- **[Aider](https://github.com/Aider-AI/aider)** [![Stars](https://img.shields.io/github/stars/Aider-AI/aider?style=social&color=white)](https://github.com/Aider-AI/aider/stargazers)  
  **AI pair programming in your terminal**, Apache-2.0 licensed. ~25k+ stars. Maps your entire codebase for context, edits multiple files, and commits changes to git with sensible messages. Supports Claude, GPT, Gemini, and local models. 🖥️

- **[Continue](https://github.com/continuedev/continue)** [![Stars](https://img.shields.io/github/stars/continuedev/continue?style=social&color=white)](https://github.com/continuedev/continue/stargazers)  
  **Open-source IDE extensions for AI coding**, Apache-2.0 licensed. ~20k+ stars. VS Code and JetBrains plugins that connect to any LLM (local or cloud). Custom autocomplete, chat, and edit experiences. 🔌

- **[Goose](https://github.com/block/goose)** [![Stars](https://img.shields.io/github/stars/block/goose?style=social&color=white)](https://github.com/block/goose/stargazers)  
  **Open-source, extensible AI agent that automates coding tasks**, Apache-2.0 licensed. By Block (Square). Runs locally, supports any LLM. Built-in extensions for coding, research, and automation. 🦢

- **[OpenCode](https://github.com/sst/opencode)** [![Stars](https://img.shields.io/github/stars/sst/opencode?style=social&color=white)](https://github.com/sst/opencode/stargazers)  
  **AI coding agent built for the terminal**, MIT licensed. Provider-agnostic, client/server architecture. Works with Claude, OpenAI, Google, and local models. TUI-based interface. 🔓

- **[Tau](https://github.com/taubyte/tau)** [![Stars](https://img.shields.io/github/stars/taubyte/tau?style=social&color=white)](https://github.com/taubyte/tau/stargazers)  
  **Small, readable Python coding agent for the terminal**, MIT licensed. ~2.9k stars. Provider-neutral core (Anthropic, Google, OpenAI-compatible, Codex). Durable JSONL sessions with branching, skills, and MCP-style extensions. Doubles as a teaching codebase for agent harness construction. 🐍

- **[Nanocoder](https://github.com/Nano-Collective/nanocoder)** [![Stars](https://img.shields.io/github/stars/Nano-Collective/nanocoder?style=social&color=white)](https://github.com/Nano-Collective/nanocoder/stargazers)  
  **Local-first CLI coding agent**, MIT licensed. ~2.5k stars. Bring your own model (Ollama, OpenRouter, any OpenAI-compatible API). Native tool calling with XML fallback, MCP support, file-based custom commands and tools. 🧬

- **[Letta Code](https://github.com/letta-ai/letta)** [![Stars](https://img.shields.io/github/stars/letta-ai/letta?style=social&color=white)](https://github.com/letta-ai/letta/stargazers)  
  **Memory-first CLI coding agent**, Apache-2.0 licensed. ~3.5k stars. Built on the Letta platform (formerly MemGPT). Persistent memory across sessions, model-agnostic (Claude/GPT/Gemini), skill learning, and context repositories. 🧠

- **[Devon](https://github.com/entropy-research/Devon)** [![Stars](https://img.shields.io/github/stars/entropy-research/Devon?style=social&color=white)](https://github.com/entropy-research/Devon/stargazers)  
  **Open-source pair programmer with TUI**, MIT licensed. ~3.5k stars. Autonomous planning, execution, and debugging in Git workflows. 👨‍💻

- **[AutoCodeRover](https://github.com/nus-apr/auto-code-rover)** [![Stars](https://img.shields.io/github/stars/nus-apr/auto-code-rover?style=social&color=white)](https://github.com/nus-apr/auto-code-rover/stargazers)  
  **Autonomous program improvement agent**, Apache-2.0 licensed. ~3.1k stars. Patches real GitHub issues using code search and analysis. 🔧

- **[RA.Aid](https://github.com/ai-christianson/RA.Aid)** [![Stars](https://img.shields.io/github/stars/ai-christianson/RA.Aid?style=social&color=white)](https://github.com/ai-christianson/RA.Aid/stargazers)  
  **Autonomous coding agent built on LangGraph**, MIT licensed. ~2.2k stars. Research/plan/implement pipeline with optional aider integration for near-full autonomy. 🧪

- **[Maki](https://github.com/maki-ai/maki)** [![Stars](https://img.shields.io/github/stars/maki-ai/maki?style=social&color=white)](https://github.com/maki-ai/maki/stargazers)  
  **Rust TUI coding agent optimized for context-token efficiency**, MIT licensed. ~1.1k stars. Tree-sitter file indexing, sandboxed `code_execution` tool, permission gating for bash commands, and memory tool. 17+ providers, MCP, ACP, Claude Code-compatible headless mode. 🦀

- **[Poseidev](https://github.com/poseidev/poseidev)** [![Stars](https://img.shields.io/github/stars/poseidev/poseidev?style=social&color=white)](https://github.com/poseidev/poseidev/stargazers)  
  **AI-powered CLI code editor**, MIT licensed. Multi-model orchestration, auto-build, and agent collaboration. Node.js-based. 🎭

- **[VT Code](https://github.com/vinhnx/vtcode)** [![Stars](https://img.shields.io/github/stars/vinhnx/vtcode?style=social&color=white)](https://github.com/vinhnx/vtcode/stargazers)  
  **Open-source coding agent with LLM-native code understanding**, MIT licensed. ~857 stars. Robust shell safety, multi-provider support with automatic failover, efficient context management. 🛡️

## 🛠️ How to Contribute

Contributions are welcome! Follow these steps to submit new AI coding assistants or open-source development agent software:

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining table/list structure and formatting.
3. 🔗 Include project title, official website/GitHub link, exact Stars_Count, license, and brief description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your changes.
